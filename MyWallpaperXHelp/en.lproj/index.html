Getting Started

Step 1: Import Videos
Click Import in the toolbar or press ⌘O. Supports MP4, MOV, M4V and any AVFoundation-decodable format. Batch import supported.

Step 2: Set as Wallpaper
Select a wallpaper, then double-click the card or press ↩ to set it as your desktop wallpaper immediately.

Step 3: Configure Playback
Click the preferences icon or press ⌘, to adjust loop, shuffle, auto-switch, and more.

Step 4: Lives in the Menu Bar
After closing the main window, MyWallpaperX keeps running in the menu bar. Click the icon to control playback or reopen the window.

Note: On first launch, macOS may prompt for permission requests required by the wallpaper engine. Please approve them.

Playback Control

Loop: The current wallpaper replays from the beginning after finishing, without switching.

Sequential: Wallpapers play in library order, wrapping back to the first after the last.

Shuffle: Each switch picks a random wallpaper, avoiding repeats until all have played.

Auto Switch: Switches on a set interval. Supports seconds, minutes, or hours.

Playback Speed: Adjust from 0.25× to 2.0× in 0.25 steps (enable in Preferences).

Volume: Set wallpaper audio volume (0–100%) independently from system volume.

Note: With Auto Switch enabled, the current video loops until the timer expires, then switches. With it disabled, the video naturally transitions to the next one.

Library Management

Import: Drag files onto the main window, or use File → Import Videos (⌘O). Batch import supported.

Favorites: Press ⌘D to favorite a wallpaper. Access favorites in the sidebar.

Tags: Press ⌘T to add custom tags. Filter by tag in the sidebar.

Bulk Delete: Press ⌘E for multi-select, then ⌘⌫ to delete. Only removes library references — original video files are never deleted.

Recents: The sidebar auto-tracks the last 25 played wallpapers for quick access.

Sort: Sort by name, import date, or last played — each category remembers its own sort order.

Backup: Export your configuration as JSON via Preferences → Export. Restore it on a new Mac via Import.

Display Settings

Thumbnail Size: Use toolbar zoom buttons or ⌘− / ⌘+ to adjust grid columns (2–6). Preference is saved automatically.

Fill Mode:
• Fit: Preserves aspect ratio; letterboxing may appear.
• Fill: Crops video to fully cover the desktop with no borders.

Multi-Display: Enable in Preferences to sync wallpaper across all connected displays.

Sync System Wallpaper: Auto-updates the macOS static wallpaper to the current video frame on each switch.

Performance & Power

Pause when another app is active: Pauses playback when another app is in the foreground, freeing GPU resources.

Pause when another app is fullscreen: Auto-pauses for games, videos, and other fullscreen apps to avoid background rendering overhead.

Pause on battery: Auto-pauses when unplugged to extend battery life.

Pause when idle: Pauses after system idle for a set duration (default: 10 min), resuming on activity.

Tip: On MacBook, enabling "Pause on battery" significantly reduces power consumption. Desktop users can disable all pause options for continuous playback.

FAQ

Why does the fan spin up after setting a wallpaper?

Video decoding uses GPU/CPU resources, especially at high resolutions. Use H.264 or HEVC-encoded videos and enable "Pause when another app is fullscreen" to reduce background rendering.

Are original video files deleted when I remove a wallpaper?

No. Removing a wallpaper only deletes its library reference and thumbnail cache. Original files on disk are never touched.

What video formats are supported?

Any format decodable by macOS AVFoundation, including MP4 (H.264/HEVC), MOV, and M4V. Formats requiring third-party decoders (e.g. MKV with unusual codecs) are not supported.

How do I make wallpapers play automatically at login?

Enable "Launch at Login" in Preferences → System. MyWallpaperX will start automatically and restore your last wallpaper state.

Thumbnails are blank or loading slowly. What should I do?

Thumbnails are generated on first load. If they stay blank, go to Preferences → Clear Cache to reset the thumbnail cache, then reopen the main window to trigger a rebuild.

How do I migrate my library to a new Mac?

On your old Mac, go to Preferences → Export Settings to save a JSON file. Copy both the config file and video files to your new Mac, then use Import Settings to restore. Video file paths must match.

Technology

Native macOS Architecture
Built entirely on Apple's native stack — SwiftUI for the declarative UI layer, AppKit for high-performance grid rendering and keyboard interaction. The two communicate through a precise state-sync mechanism, eliminating the rendering jitter common in hybrid frameworks.

Dual-Process Wallpaper Engine
Playback runs in a dedicated XPC Daemon process (WallpaperDaemon), fully isolated from the main app. A main process crash won't interrupt your wallpaper; a daemon crash auto-restarts and restores playback state. The two communicate via a custom XPC protocol with sub-millisecond latency.

AVFoundation Hardware Decoding
The video layer is built on AVFoundation + AVSampleBufferDisplayLayer, routing all decoding through Apple Silicon / Intel hardware (VideoToolbox). CPU usage is minimal — 4K HEVC on an M-series chip draws under 1W, virtually imperceptible in daily use.

High-Performance Thumbnail Pipeline
Thumbnails use a multi-tier cache: in-memory LRU cache (up to 360 entries) + persistent disk cache. First-time generation asynchronously extracts keyframes via AVAssetImageGenerator; subsequent loads hit memory instantly, keeping the grid scrolling at a steady 60 fps.

Reactive State Management
The data layer is built on Combine + @Published, forming a reactive state tree where all UI changes are driven by a single source of truth. Delete, favorite, tag, and selection operations are atomically committed on the main thread, guaranteeing strong consistency between UI and data.

Intelligent System Awareness
Three signal sources — IOKit power state monitoring, NSWorkspace screen sleep and fullscreen event subscriptions, and a system idle timer — are fused to respond to system state changes in milliseconds, automatically pausing or resuming playback while balancing experience and battery life.
