快速上手

第一步：导入视频
点击工具栏「导入」按钮，或按 ⌘O，选择本地视频文件（支持 MP4、MOV、M4V 等格式）导入壁纸库。支持批量选择多个文件。

第二步：设为壁纸
在壁纸库中单击选中一张视频，双击卡片或按 ↩ 回车键，即可立即将其设为桌面壁纸。

第三步：调整播放设置
点击工具栏右侧偏好设置图标，或按 ⌘,，在「播放」分区调整循环、随机、自动切换等选项。

第四步：常驻菜单栏
关闭主窗口后，MyWallpaperX 将继续在菜单栏托盘运行。点击托盘图标可快速控制播放、切换壁纸或重新打开主界面。

提示：首次启动时，系统可能弹出权限请求，这是壁纸引擎正常工作所必需的，请点击「好」授权。

播放控制

循环播放：开启后，单张壁纸播放结束后从头重播，不自动切换到下一张。

顺序播放：按壁纸库排列顺序依次切换，播放到最后一张后回到第一张。

随机播放：每次切换时从壁纸库中随机选择下一张，尽量不重复。

自动切换：按设定的时间间隔自动切换壁纸，间隔时间支持秒、分钟或小时单位。

播放速率：在偏好设置中开启后，可将视频播放速率调整为 0.25× 至 2.0×，步长 0.25。

音量控制：独立调整壁纸视频的音量（0–100%），静音开关不影响其他应用的系统音量。

注意：开启「自动切换」后，当前视频将循环播放直至计时器到期再切换下一张。关闭后，视频播完会自然过渡到下一张（取决于顺序/随机设置）。

壁纸库管理

导入视频：支持拖放文件到主窗口，或通过菜单「文件 → 导入视频」（⌘O）批量导入。

收藏：选中壁纸后按 ⌘D，收藏的壁纸可在侧边栏「收藏」分类中快速访问。

标签：按 ⌘T 为壁纸添加自定义标签，在侧边栏按标签筛选浏览。

多选删除：按 ⌘E 进入多选模式，框选或逐一点击多张壁纸，再按 ⌘⌫ 批量删除。删除操作仅移除库中的引用，不会删除原始视频文件。

最近使用：侧边栏「最近使用」自动记录最近播放的 25 张壁纸，方便快速回切。

排序：工具栏「排序」按钮支持按名称、导入时间、最近播放时间等排序，每个分类独立保存排序状态。

配置备份：在「偏好设置 → 导出个人设置」中导出为 JSON 文件，换机后通过「导入个人设置」恢复。

🖥

显示设置

缩略图大小：使用工具栏缩放按钮或快捷键 ⌘− / ⌘+ 调整网格列数（2–6 列），偏好自动保存并在下次启动时恢复。

视频填充模式：

• 适应（Fit）：保持视频原始比例，两侧可能出现留白。
• 填充（Fill）：裁剪视频以完全覆盖桌面，不留边框。

多屏适配：在偏好设置中开启「多屏适配」后，所有已连接显示器将同步播放同一壁纸。

同步系统壁纸：开启后，每次切换壁纸时自动将视频当前帧同步为系统静态壁纸，方便截图或锁屏显示。

性能与电源管理

其他应用获得焦点时暂停：当前台有其他应用运行时暂停壁纸播放，释放 GPU 资源。

其他应用全屏时暂停：检测到游戏、视频等全屏应用时自动暂停，避免后台占用帧率。

未连接电源时暂停：使用电池供电时自动暂停播放，延长续航时间。

电脑不活跃时暂停：系统闲置超过设定时间（默认 10 分钟）后暂停播放，恢复活动后自动继续。

建议：在 MacBook 上建议开启「未连接电源时暂停」，可显著降低电池消耗。台式机用户可关闭所有暂停选项以获得连续播放体验。

常见问题

为什么壁纸播放后系统风扇转速上升？

视频解码会占用 GPU/CPU 资源，高分辨率视频尤为明显。建议使用 H.264 或 HEVC 编码的视频，并开启「其他应用全屏时暂停」减少不必要的后台渲染。

删除壁纸后，原始视频文件还在吗？

在。MyWallpaperX 的删除操作仅从壁纸库中移除引用记录及缩略图缓存，不会删除磁盘上的原始视频文件。

支持哪些视频格式？

支持 macOS AVFoundation 框架能解码的所有格式，包括 MP4（H.264/HEVC）、MOV、M4V 等。不支持需要第三方解码器的格式（如 MKV、AVI 含特殊编码）。

如何让壁纸开机自动播放？

在「偏好设置 → 系统 → 开机自启动」中开启即可。MyWallpaperX 会在登录时自动启动并恢复上次的壁纸设置。

缩略图显示空白或加载缓慢怎么办？

缩略图首次加载需要生成缓存，请耐心等待。若长时间空白，可在「偏好设置 → 清空缓存」中重置缩略图缓存，再重新打开主界面触发重建。

更换 Mac 后如何迁移壁纸库？

在旧 Mac 上通过「偏好设置 → 导出个人设置」导出 JSON 配置文件，将配置文件与视频文件一同复制到新 Mac，再通过「导入个人设置」恢复。注意视频文件路径需与导出时保持一致。

技术实现

原生 macOS 架构
MyWallpaperX 完全采用 Apple 原生技术栈构建——SwiftUI 负责声明式界面层，AppKit 处理高性能网格渲染与键盘交互，两者通过精确的状态同步机制无缝协同，避免了混合框架常见的性能损耗与渲染抖动。

双进程壁纸引擎
壁纸播放由独立的 XPC Daemon 进程（WallpaperDaemon）承载，与主进程完全隔离。主进程崩溃不影响壁纸继续播放；Daemon 崩溃会自动重启并恢复播放状态。两者通过自定义 XPC 协议通信，延迟控制在毫秒级以内。

AVFoundation 硬件解码
视频播放层基于 AVFoundation + AVSampleBufferDisplayLayer，全程走 Apple Silicon / Intel 硬件解码通道（VideoToolbox），CPU 占用极低。4K HEVC 视频在 M 系列芯片上解码功耗不足 1W，对日常使用几乎无感知。

高性能缩略图管道
缩略图采用多级缓存架构：内存 LRU 缓存（最多 360 张）+ 磁盘持久化缓存。首次生成通过 AVAssetImageGenerator 异步提取关键帧，后续加载直接命中内存缓存，网格滚动帧率稳定在 60fps。

精准的状态管理
核心数据层基于 Combine + @Published 构建响应式状态树，所有 UI 变更由单一数据源驱动，彻底消除多处状态不一致问题。删除、收藏、标签、选中态等操作均在主线程原子提交，保证界面与数据的强一致性。

智能系统感知
通过 IOKit 实时监听电源状态、NSWorkspace 订阅屏幕睡眠与应用全屏事件、系统空闲计时器三路信号融合，在毫秒级内响应系统状态变化，自动暂停或恢复播放，兼顾流畅体验与电池续航。
