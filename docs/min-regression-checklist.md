# Minimal Regression Checklist

## 1. 播放模式

1. 打开“循环播放”，关闭“随机/顺序”，关闭“自动切换”。
2. 预期：当前单张壁纸持续循环，不切换到下一张。
3. 打开“随机播放”并打开“自动切换（例如 10 秒）”。
4. 预期：10 秒内重复当前视频，计时结束后随机切下一张。
5. 打开“顺序播放”并打开“自动切换（例如 10 秒）”。
6. 预期：10 秒内重复当前视频，计时结束后按列表顺序切下一张，最后一张后回第一张。

## 2. 导入去重

1. 在“我的壁纸”导入同一批视频（例如 30 个）两次。
2. 预期：第二次导入不新增重复项，导入结果包含“已存在/已重复”的数量。
3. 在标签列表中导入同一批文件。
4. 预期：文件仍归入“我的壁纸”总库，标签页只增加引用关系，不生成重复实体。

## 3. 删除一致性

1. 在“最近使用”删除一张壁纸。
2. 预期：仅从“最近使用”移除，“我的壁纸”中仍存在。
3. 在“我的壁纸”删除一张已收藏且带标签的壁纸。
4. 预期：该条目同时从“最近使用/收藏/标签列表”消失，且相关缓存被清理。

## 4. 设置持久化

1. 修改以下设置后退出应用并重启：
   - 播放模式
   - 自动切换间隔
   - 音量/静音
   - 系统行为开关
2. 预期：重启后设置值保持一致。
3. 调整侧边栏宽度后退出并重启。
4. 预期：侧边栏宽度恢复到退出前状态。
