# AppKit Migration Baseline & Current Snapshot

## Scope

目标：在不改变当前功能行为与 UI 风格前提下，把主界面迁移到 AppKit，并保持单一路径实现。
当前阶段：Phase 5 收口（清理冗余实现与目录映射，功能行为不改）。

## Current Rendering Entry

1. 主窗口：`NSWindow + NSHostingController(ContentView)`（窗口交互由 AppKit 主控制器承接）
2. 主容器：`NSSplitViewController`（`AppKitMainSplitView`）
3. 侧边栏：`NSOutlineView`（`AppKitSidebarView`）
4. 网格：`NSCollectionView + DiffableDataSource`（`AppKitLibraryGridView`）
5. 设置页：`NSScrollView + NSStackView`（`AppKitSettingsView`）
6. 当前策略：网格/侧边栏/设置均为 AppKit 单路径，无 SwiftUI 生效分支。

## Behavior Baseline Checklist

### A. 导航与选择

1. 侧边栏切换“我的壁纸/特别喜爱/标签/最近使用/设置”正常。
2. 进入设置页时，工具栏状态不误触发网格选择逻辑。
3. 点击空白区域可退出单选态。
4. 多选模式下框选、批量操作、切换列表自动退出规则正常。

### B. 网格与卡片

1. 单击卡片进入选中态，再次点击同卡片不反选。
2. 双击卡片直接设为壁纸。
3. 播放图标在 hover 或当前播放态显示。
4. 收藏角标与工具栏收藏状态一致。
5. 缩略图缺失时自动补生成，生成后当前列表实时刷新。

### C. 播放与切换

1. 手动下一张/上一张按钮和快捷键可用。
2. 切换不同壁纸有过渡，同一壁纸循环不闪。
3. 随机/顺序/循环与自动切换间隔策略符合定义。
4. 播放失败自动切下一张。

### D. 导入与删除

1. 导入弹窗即时反馈，不等待缩略图/静帧全量生成。
2. “我的壁纸”删除会联动从其他列表移除；其他列表删除不影响“我的壁纸”主索引。
3. 删除只删引用与缓存，不删磁盘源文件。
4. 删除失败时才弹失败信息。

### E. 系统行为

1. 其他应用焦点/全屏、未接电源、闲置超时暂停策略生效。
2. 睡眠/息屏/唤醒自动启停生效。
3. 状态栏入口、主窗显示隐藏、Dock 策略正常。

## Performance Baseline Capture

### 场景 1：冷启动

1. 启动应用到主窗口可交互（可点击侧边栏）时间。
2. 启动到当前壁纸开始播放时间。

### 场景 2：大库滚动

数据量：300/600/1000 文件三档。  
记录：
1. 首次进入列表首屏出现时间。
2. 连续滚动 10 秒是否明显掉帧/卡顿。
3. 缩略图补生成期间滚动体感是否被打断。

### 场景 3：频繁切换

1. 1 秒内连续点击下一张 5 次，应用不应卡死。
2. 自动切换连续 50 次，观察闪烁和恢复延迟。

## Phase 5 Exit Criteria

满足以下条件后，迁移收口可视为完成：

1. 上述基线行为全部可复现、可人工回归。
2. 迁移后无双路径、无未引用过渡文件、无无效入口配置。
3. 当前构建稳定：`xcodebuild` 可通过。
