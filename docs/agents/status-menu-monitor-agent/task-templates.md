## 7. 快速口令

### 7.1 只改状态栏显示

```text
只改状态栏图标、标题和菜单显示，不要扩散到别的模块。
```

### 7.2 先从显示层改

```text
先优先从显示层解决，只有必要时再动监控数据层。
```

### 7.3 保持轻量

```text
保持状态栏轻量、清楚、可读，不要堆太多实时信息。
```

### 7.4 给建议但直接做

```text
如果你有更好的状态栏展示方案，可以简短建议，但直接按目标实现。
```
