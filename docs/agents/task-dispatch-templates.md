# MyWallpaperX 任务派发模板

> 用途：我作为项目负责人，给多 Agent 系统下任务时直接复用
> 最后更新：2026-04-03

---

## 1. 总原则

我发任务时，不直接说“去改”。

我先要求机器人：

1. 先扫描
2. 再判责
3. 再决定谁实施
4. 最后再输出 diff patch

所有模板默认继承以下规则：

- 禁止跨模块直接调用
- 所有跨模块通信必须走 Notification
- 不允许随意修改 `Core/`、`Shared/`
- 所有修改必须使用 diff patch 输出
- 如果存在越界或错误方案，必须先输出 `【越界风险】` 或 `【方案纠偏】`
